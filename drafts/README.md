## Article personnel : "L'IA, l'anneau et moi"

### Thème central
Le rapport ambivalent avec l'IA : fascination et répulsion.
Comme Gollum et l'anneau — on aime et on déteste.

- Technologie excitante, innovante, presque magique
- Mais le carnage écologique et social qu'elle entraîne répugne
- L'angoisse de se faire remplacer si on se forme pas
- La pression de rester pertinent, expert, ou au moins compétent

### La réponse : domestiquer l'IA
Construire son propre workflow, sur sa propre infra, avec ses propres règles.
- L'IA bosse pour toi, pas l'inverse
- Sous ton contrôle (plan → approve)
- Sur ton temps libre (pas en mode "je dois tout apprendre, vite")
- Pour toi (pas pour un truc qui te remplace)

### Le vrai bénéfice : des projets qui n'existeraient pas
- Se débarrasser progressivement des GAFAM — un doux rêve réalisable
- Pas en payant un autre fournisseur (Proton) — en construisant soi-même
- Projets perso : jeu vidéo LDVELH, support JDR, notes de campagne, stats
- Temps développeur solo avec une vie à côté = intenable sans agent
- Dicter des idées sur le téléphone → agent les réalise

### Dev agentique pas vibe coding
- Pas un concept à la mode
- Juste la manière la plus efficace d'utiliser ces outils
- Pas une révolution, juste utiliser l'outil comme il mérite de l'être
- Agent = bien plus efficace que chatbot web
- Apprendre à connaître les outils → plus pertinent → former ses collègues

### Le workflow
- Je regarde le code généré, je dis "là ça pue, refacto"
- Je donne mes ordres à l'agent
- Sessions de travail pour que le code ressemble à ce que j'aurais écrit
- Je passe de codeur à architecte/réviseur/orchestrateur

### Structure envisagée
1. Le constat : temps limité, curiosité débordante, envie de produire
2. L'angoisse : l'IA qui avance, le monde qui change, la peur d'être obsolète
3. La révélation : on peut la domestiquer, pas la subir
4. La concrétisation : les projets perso qui naissent de cette approche
5. La boucle : former ses collègues, prendre de l'avance, reproduire au taf
